EasyReader 使用帮助 / Support

中文

更新日期：2026 年 10 月 29 日。EasyReader 是面向 iOS 17 及以上 iPhone 的本地文档阅读器。个人开发者：区倩芹。支持邮箱：celery_ou@163.com。

导入与阅读

在书库中选择导入，可从文件、下载 URL 或局域网上传导入 PDF、EPUB、Markdown 和单个 .html。当前不支持 MOBI、AZW3、.htm、网页资源目录或网页压缩包。

导入上限：PDF 200 MiB，EPUB 压缩文件 50 MiB，Markdown 2 MiB，HTML 10 MiB。EPUB 解压总量上限 200 MiB、单条目 20 MiB、最多 10,000 条、压缩比上限 100:1。需要足够的可用存储空间；支持的扩展名不代表文件未损坏。URL 应指向可直接下载的文件；GitHub 文件展示链接会转换为原始文件链接。

Markdown 默认预览正文与内嵌 HTML，代码围栏仍显示代码。HTML、Markdown 文档脚本关闭，自动外部资源请求受限，缺少的网页资源不会自动补齐。外部链接在用户点击后交给系统浏览器。PDF 保持固定版式；无文字层的扫描 PDF 不支持文字搜索，App 不提供 OCR。EPUB 需要不含 DRM，复杂排版可能与原出版物不同。

翻页与外观

拖动底部阅读进度条可预览目标页码或百分比，松手后跳转；退出阅读后会保存位置。

在正文中左滑下一页、右滑上一页；PDF 按文档页翻页，其余格式按完整排版页移动，EPUB 可跨章。翻页从右下角卷起，短距离拖动可取消；连续模式的 PDF 也支持左右翻页。轻触非链接正文进入全屏沉浸阅读，再轻触退出。纵向滚动、文字选择与缩放仍可使用；放大或选字时暂停手势翻页，横向代码块可自行滚动。

在阅读外观选择“夜间”会让整个 App 使用深色；“白色”使用浅色界面。“跟随系统”让全 App 跟随系统设置。PDF 和 HTML 保留原文件配色，不强制反色。

Wi-Fi 上传

让电脑与手机位于同一可互访的 Wi-Fi 网络，开启上传并在另一台设备的浏览器打开完整会话链接（可通过系统分享或隔空投送发送）。当前需要 Wi-Fi IPv4；如出现系统提示，请允许本地网络访问。HTTP 未加密，请只在可信网络使用，不要公开会话链接。

离开上传页仍可上传。可短暂切到其他 App 分享完整链接，然后返回 EasyReader。切到后台或锁屏会尝试延续最多 2 分钟，iOS 可能提前暂停；返回前台且 Wi-Fi 未变化时会尝试恢复同一链接。已入库文件保留，未完成文件可能需要重试。为完成较大文件上传，建议让 App 保持前台。

手动关闭、Wi-Fi 变化或 App 被结束后需要重新开启并分享新链接。若返回前台后无法恢复原链接，请按提示重新开启。无法连接时，检查本地网络权限、Wi-Fi 地址以及访客网络是否隔离设备。

GitHub 同步

本地阅读不需要 GitHub。使用同步时，在设置中连接 GitHub，再选择并校验仓库、分支和根目录。若 App 提示“未配置 GitHub”，请联系支持，不要发送或粘贴 client secret、密码或访问令牌。

先预览，再确认上传或下载；遇到冲突时选择本地、GitHub 或保留两份后重新查看预览。部分失败只重试未完成项；若上次结果不确定，先完成恢复流程。当前单文件 GitHub 上传上限 50 MiB，大 PDF 仍可留在本机阅读。

公开仓库内容可被他人读取。仅本机删除与两端删除是不同操作；远端删除不会清除 Git 历史。断开连接会移除本机凭据，不删除文档；可在 GitHub 设置中进一步撤销授权。

常见问题

  • 导入失败：检查真实格式、大小、设备可用空间、网络及下载响应。损坏文件或不受支持的加密文件需要重新导出。
  • 同步失败：检查授权、仓库权限、分支和根目录。内容已变化时重新预览，不要强行覆盖冲突。
  • 书签位置失效：文档内容更新可能改变锚点，请打开目标位置后重新定位书签。
  • 阅读位置或排版异常：记录格式、操作步骤和是否修改过文件。优先提供可公开分享的最小示例，不发送私人原文。

English

Updated: October 29, 2026. EasyReader is a local document reader for iPhone with iOS 17 or later. Individual developer: 区倩芹. Support: celery_ou@163.com.

Import and reading

Use the library's import action to choose Files, a download URL or local-network upload. Supported formats are PDF, EPUB, Markdown and a single .html file. MOBI, AZW3, .htm, webpage asset folders and webpage archives are not supported.

Import limits are PDF 200 MiB, compressed EPUB 50 MiB, Markdown 2 MiB, and HTML 10 MiB. EPUB extraction is limited to 200 MiB total, 20 MiB per entry, 10,000 entries and a 100:1 compression ratio. Enough free storage is required; a supported extension does not make a damaged file valid. URLs should point to downloadable files; GitHub file-view links are converted to raw file links.

Markdown previews content and embedded HTML while fenced code stays code. HTML and Markdown scripts are disabled, automatic external requests are restricted and missing assets are not fetched. External links open in the system browser after you choose them. PDF keeps its fixed layout; image-only PDFs have no text search, and the app does not provide OCR. EPUB must be DRM-free; complex layouts may differ from the original publication.

Page turns and appearance

Drag the reading progress slider to preview a page or percentage, then release to jump. Your position is saved when you leave reading.

Swipe left in document content to move forward, or right to move back. PDF turns by document page; other formats move by complete layout pages, with EPUB chapter transitions. Turns curl from the lower-right corner, and short drags cancel. PDF also supports horizontal page changes in continuous mode. Tap non-link content to enter immersive reading, then tap again to leave. Vertical scrolling, text selection and zoom remain available. Page-turn swipes pause while zoomed or selecting text, and horizontal code blocks retain their own scrolling.

Choosing Night in reading appearance applies dark mode throughout the app. White uses a light interface. Follow System applies the system appearance throughout the app. PDF and HTML retain their original document colors without forced inversion.

Wi-Fi upload

Keep your computer and iPhone on the same reachable Wi-Fi network, start upload and open the complete session link in the other device's browser (you can send it to trusted devices using the system share sheet or AirDrop). Wi-Fi IPv4 is currently required. Allow local-network access when iOS asks. HTTP is unencrypted; use a trusted network and do not make the session link public.

Leaving the upload page keeps upload enabled. You can briefly switch to another app to share the complete link, then return to EasyReader. Backgrounding or locking attempts to continue for up to two minutes, but iOS may suspend it earlier. Returning to the foreground attempts to restore the same link if Wi-Fi is unchanged. Completed imports remain; unfinished files may need retrying. Keep the app in the foreground when uploading larger files.

After closing upload, changing Wi-Fi or terminating the app, start again and share the new link. If the original link cannot be restored after returning to the foreground, follow the prompt to restart upload. If you cannot connect, check local-network permission, the Wi-Fi address and whether a guest network isolates devices.

GitHub sync

Local reading does not require GitHub. For sync, connect GitHub in Settings, then select and validate a repository, branch and root folder. If the app reports that GitHub is not configured, contact support; do not send or paste client secrets, passwords or access tokens.

Preview before confirming uploads or downloads. Resolve conflicts using local, GitHub or both copies, then review the preview again. Retry only unfinished items after a partial failure. If an earlier result is uncertain, complete recovery first. GitHub uploads currently allow at most 50 MiB per file; larger supported PDFs can still be read locally.

Public repositories expose their content to others. Local-only removal differs from deletion from both locations. Remote deletion does not erase Git history. Disconnecting removes the local credential without deleting documents; you can also revoke authorization in GitHub settings.

Troubleshooting

  • Import fails: check the actual format, size, free storage, network and download response. Damaged files or unsupported encrypted files may need re-exporting.
  • Sync fails: check authorization, repository permissions, branch and root folder. Re-preview changed content instead of forcing an overwrite.
  • Bookmark cannot restore: changed document content may invalidate an anchor. Open the intended position and relocate the bookmark.
  • Reading position or layout differs: note the format, steps and whether the file changed. Prefer a minimal sample safe to share publicly over a private original.
