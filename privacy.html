EasyReader 隐私政策 / Privacy Policy

中文

更新日期：2026 年 10 月 26 日。适用于 EasyReader iPhone App 及其隐私政策、支持网站。个人开发者：区倩芹。联系邮箱：celery_ou@163.com。

1. 本机保存与用途

EasyReader 在设备内保存导入的文档、标题等元数据、分类、书签、阅读位置、偏好与恢复记录，用于管理和阅读。导入来源 URL 也保存在本机，可能包含私人信息。旧数据迁移会保留原文件和索引用于恢复；移除活跃记录不等于安全擦除历史备份。

App 没有开发者运营的文档云端后台，未接入广告或行为分析 SDK，不出售用户数据，不进行跨 App 或网站广告跟踪。本地阅读无需 GitHub 账号。你主动使用的网络功能会将必要数据发送给下述服务。

2. URL 导入与文档外链

URL 导入访问你提供的地址及其重定向地址以下载文件；GitHub 文件展示链接会转换为原始文件下载链接。目标服务器会接收 IP 地址、请求地址及普通网络请求信息，并按其政策处理。请勿向不可信地址提供带有凭据的 URL。

HTML 和 EPUB 文档脚本关闭，自动外部资源请求受到限制，不会补抓网页资源目录。用户主动点击允许的外部链接时，由系统浏览器访问，适用目标网站的隐私政策。

3. 局域网上传

你开启上传后，同一可达 Wi-Fi 网络内持有本次会话链接的设备可以发送文档到 iPhone。链接含临时访问凭据，请勿向他人公开。服务使用未加密 HTTP，仅适合可信网络；当前需要 Wi-Fi IPv4。关闭服务、锁屏或离开前台会停止接收并使会话链接失效。已入库文件保留，未完成项可能需要重试。该传输不经过开发者服务器。

4. 可选 GitHub 授权与同步

GitHub 连接使用 Device Flow。GitHub 处理授权、账号标识、仓库信息和网络请求；App 读取仓库所有者标识、名称、分支及权限以配置和校验连接。授权凭据保存在 iOS Keychain，不写入书库索引，不发送给开发者。App 不读取你的 GitHub 账号邮箱或要求填写 GitHub 密码。

预览并确认同步后，文档、标题、分类、书签、阅读位置、进度及其更新时间等信息可以存入你指定的 GitHub 仓库。账号标识、用户内容和阅读交互信息用于账号连接、文件存储与跨设备同步，可关联至 GitHub 账号；不用于广告、行为分析或跟踪。GitHub 在设备外保存这些信息，因此可选同步不能描述成“所有数据始终只留在本机”。

v2 同步索引 .reader/library-v2.json 不包含本机路径、导入来源 URL 或局域网凭据。旧版 .reader/library.json 仅在迁移时读取并保留；迁移不会删除旧索引或 Git 历史中原有的信息。公开仓库中的上传内容可被他人访问，请检查仓库可见性。GitHub 的处理和保留规则见 GitHub 隐私声明。

5. 保留、删除与断开连接

本地文档和阅读记录保留到你主动移除或卸载 App；迁移备份、恢复文件和系统备份可能保留历史副本。对于有远端副本的文档，可选择仅移除本机文件，或预览确认两端删除。仅移除本机会保留远端文件及可下载条目；两端删除会更新所选仓库的当前文件和索引。删除分类不会删除其中的文档。

远端删除不清除 Git 提交历史、分叉、克隆或他人已经获取的副本；如需清除历史，请使用 GitHub 的仓库管理功能并参阅其支持指引。断开 GitHub 会移除本机授权凭据，不删除本机或远端文档；也可在 GitHub 设置中撤销应用授权。卸载 App 不保证删除 Keychain 凭据或设备备份，需要移除凭据时请先断开连接。

开发者无法访问或代你删除私人书库或私人仓库。有关本政策或数据处理的查询、纠正和删除请求，请通过下方邮箱联系；针对 GitHub 或下载站点保存的数据，需向对应服务提出请求。

6. 支持邮件与网站

主动发送支持邮件时，开发者会收到你的邮箱地址、邮件内容以及你选择提供的附件，仅用于回复、排查问题和处理隐私请求。不要求提交真实文档、密码、令牌或会话链接。支持邮件保留至问题处理完成后的 12 个月内；你可要求提前删除，依法必须保留的情况除外。

政策与支持网站由 GitHub Pages 托管，页面不包含广告、统计脚本、表单或第三方字体。访问网站时，GitHub 作为托管方可能记录 IP 地址和访问日志以保障服务与安全；适用其隐私声明。这与 App 内的本地阅读处理不同。

7. 联系与更新

个人开发者：区倩芹。邮箱：celery_ou@163.com。重大变更会更新本政策和顶部日期；使用帮助见支持页。

English

Updated: October 26, 2026. This policy covers the EasyReader iPhone app and its privacy and support website. Individual developer: 区倩芹. Contact: celery_ou@163.com.

1. Local storage and purposes

EasyReader stores imported documents, metadata such as titles, categories, bookmarks, reading positions, preferences and recovery records on your device for library management and reading. Import source URLs are also stored locally and may contain private information. Migration preserves original files and indexes for recovery; removing an active record does not securely erase historical backups.

The app has no developer-operated document backend, advertising SDK or behavioral analytics SDK. It does not sell user data or track you across apps or websites for advertising. Local reading does not require a GitHub account. Network features you choose to use send necessary data to the services below.

2. URL import and external links

URL import requests your supplied address and redirects to download a file. GitHub file-view links are converted to raw download links. Destination servers receive your IP address, requested URL and ordinary network request information and process it under their policies. Do not give credential-bearing URLs to untrusted destinations.

Document scripts are disabled for HTML and EPUB, and automatic external resource requests are restricted. Missing webpage asset folders are not downloaded. When you choose an allowed external link, the system browser opens it and the destination's privacy policy applies.

3. Local-network upload

After you start upload, devices on the same reachable Wi-Fi network with the session link can send documents to your iPhone. The link contains a temporary credential; keep it private. The service uses unencrypted HTTP and requires a trusted network; it currently needs Wi-Fi IPv4. Closing upload, locking the device or leaving the foreground stops receiving and invalidates the link. Completed imports remain; unfinished items may need retrying. Transfers do not pass through a developer server.

4. Optional GitHub authorization and sync

GitHub connection uses Device Flow. GitHub handles authorization, account identifiers, repository information and network requests. The app reads repository owner identifiers, names, branches and permissions to configure and validate the connection. Authorization credentials are stored in iOS Keychain, not in the library index or on a developer server. The app does not read your GitHub account email or ask for your GitHub password.

After you preview and confirm sync, documents, titles, categories, bookmarks, reading positions, progress and update timestamps may be stored in your chosen GitHub repository. Account identifiers, user content and reading interaction information support account connection, file storage and cross-device sync and can be linked to your GitHub account. They are not used for advertising, analytics or tracking. GitHub stores this information off-device; optional sync therefore does not mean that all data always stays on-device.

The v2 index, .reader/library-v2.json, excludes local paths, import source URLs and LAN credentials. Legacy .reader/library.json files are read only for migration and retained. Migration does not remove information already in a legacy index or Git history. Public repositories expose uploaded content to others; check repository visibility. GitHub's processing and retention practices are described in the GitHub General Privacy Statement.

5. Retention, deletion and disconnection

Local documents and reading records remain until you remove them or uninstall the app; migration backups, recovery files and system backups may retain historical copies. For documents with a remote copy, choose local-only removal or preview and confirm deletion from both locations. Local-only removal preserves the remote file and a downloadable entry. Both-location deletion updates the selected repository's current file and index. Deleting a category does not delete its documents.

Remote deletion does not erase Git commit history, forks, clones or copies obtained by others. Use GitHub's repository controls and support guidance to manage history. Disconnecting GitHub removes the local authorization credential without deleting documents. You may also revoke the app authorization in GitHub settings. Uninstalling does not guarantee removal of Keychain items or device backups; disconnect first if you want the credential removed.

The developer cannot access or delete your private library or private repository for you. Contact the email below with questions, correction or deletion requests about data processing. Requests about data retained by GitHub or download sites should be directed to those services.

6. Support email and website

If you send a support email, the developer receives your email address, message and any attachments you choose to send, solely to reply, troubleshoot and handle privacy requests. Do not send private documents, passwords, tokens or session links. Support emails are retained for up to 12 months after the issue is resolved. You may request earlier deletion, except where retention is legally required.

The privacy and support website is hosted on GitHub Pages. Its pages contain no advertising, analytics scripts, forms or third-party fonts. GitHub, as the host, may record IP addresses and access logs for service operation and security under its privacy statement. This is separate from local reading in the app.

7. Contact and changes

Individual developer: 区倩芹. Email: celery_ou@163.com. Material changes will update this policy and its date. See the support page for help.
